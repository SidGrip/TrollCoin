# Security Policy

## Reporting a Vulnerability

TrollCoin is network-critical software. Please report security issues
**privately** — do not open a public issue or pull request for a vulnerability.

- Preferred: use GitHub's private vulnerability reporting on this repository
  (the **Security** tab → **Report a vulnerability**).
- Project site: https://trollcoin.com

Please include a description, the affected version or commit, and reproduction
steps. Allow maintainers reasonable time to prepare and release a fix before any
public disclosure.
